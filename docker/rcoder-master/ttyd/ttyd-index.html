🖥️ ttyd + xterm.js 本地测试

Web 终端协议验证 · 前后端协作 demo

使用步骤：
1. 启动容器：cd demo && docker build -t ttyd-demo . && docker run --rm -p 7681:7681 ttyd-demo
2. 浏览器打开 http://localhost:7681（容器内置 UI）或运行 ./serve.sh 然后访问 http://localhost:8000
3. 点击「连接」开始测试 · 输入 ls -la /home/demo 验证
