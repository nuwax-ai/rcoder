# 9. 操作与运维接口

> 补充 [02-接口手册](./02-接口手册.md) 中未覆盖的操作类接口：启停/重启、回收策略、URL 上传、存储销毁、数据库管理。

---

## 操作

### POST `/apps/{app_id}/start` — 启动应用

scale replicas → 1。应用之前被 stop/recycle 后用此接口恢复。

**请求体**：无

**响应** `HttpResult<AppRuntimeInfo>`：
```jsonc
{
  "success": true,
  "data": {
    "app_id": "app-order-svc",
    "status": "running",
    "phase": "running",
    "replicas": 1,
    "ready_replicas": 1
  }
}
```

**错误**：
| HTTP | code | 说明 |
|---|---|---|
| 404 | ERR_APP_NOT_FOUND | 应用不存在 |

**curl**：
```bash
curl -X POST $RCODER/api/v1/apps/app-order-svc/start
```

---

### POST `/apps/{app_id}/stop` — 停止应用

scale replicas → 0。计算面释放，**持久存储保留**。

**请求体**：无

**响应** `HttpResult<AppRuntimeInfo>`：status 变为 `Stopped`，replicas=0。

**错误**：同 start（404）。

**curl**：
```bash
curl -X POST $RCODER/api/v1/apps/app-order-svc/stop
```

> **stop vs delete**：stop 只缩容到 0（PVC/Service/路由保留，数据零丢失），随时 start 恢复；delete 删除计算面（Deployment+Service），**保留 PVC**；`delete + purge:true` 连 PVC 一起清。

---

### POST `/apps/{app_id}/restart` — 重启应用

滚动重启（rollout restart）。已有 Pod 逐个重建，服务不中断。

**请求体**：无

**响应** `HttpResult<AppRuntimeInfo>`。

**curl**：
```bash
curl -X POST $RCODER/api/v1/apps/app-order-svc/restart
```

---

### POST `/apps/{app_id}/recycle-policy` — 设置闲置回收策略

动态调整回收策略，**免重启**：strategic-merge Deployment 注解，不碰 pod template → 不触发 rollout，下个回收扫描周期生效（默认 1 小时）。

**请求体** `RecyclePolicyRequest`：
```jsonc
{
  "recycle_enabled": true,        // 是否参与闲置自动回收（true=可回收，免费用户默认）
  "idle_timeout_seconds": 432000   // 闲置超时阈值秒数（可选；覆盖全局 5 天默认值）
}
```

> 两字段至少传一个，全空返回 400。

**响应** `HttpResult<AppRuntimeInfo>`。

**curl**：
```bash
# 设为永不回收（付费/常驻）
curl -X POST $RCODER/api/v1/apps/app-order-svc/recycle-policy \
  -H 'Content-Type: application/json' \
  -d '{"recycle_enabled": false}'
```

## 文件管理

### POST `/apps/{app_id}/upload-from-url` — 从 URL 下载文件并上传

rcoder 服务端从指定 URL 下载文件/压缩包，解压后部署到应用工作目录。适合 CI/CD 场景（构建产物在内部 HTTP 服务上）。

**请求体** `UploadFromUrlRequest`：
```jsonc
{
  "url": "https://ci.example.com/build/app.jar",  // 下载地址（HTTP/HTTPS）
  "target": "code/",                               // 目标路径（app 根相对；默认 "code/"）
  "flatten": false                                 // 压缩包是否剥单层 wrapper 目录
}
```

**响应** `HttpResult<UploadResult>`：
```jsonc
{
  "success": true,
  "data": {
    "file_path": "code/app.jar",
    "file_size": 10485760,
    "uploaded_at": "2026-08-15T10:00:00Z",
    "extracted_count": 5,
    "path": "code/",
    "size": 10485760,
    "is_dir": true
  }
}
```

**错误**：
| HTTP | code | 说明 |
|---|---|---|
| 400 | ERR_VALIDATION | URL 非法或不是 HTTP(S) |
| 404 | ERR_APP_NOT_FOUND | 应用不存在 |

**curl**：
```bash
curl -X POST $RCODER/api/v1/apps/app-order-svc/upload-from-url \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://ci.internal/build-42/app.jar","target":"code/"}'
```

## 持久存储管理

### POST `/apps/{app_id}/storage/destroy` — 销毁应用持久存储 PVC（⚠️ 高危·不可逆）

释放存储配额。**仅当应用已 delete 后才允许**（否则 409），且需 `confirm=app_id` 防误操作。PVC 删除后数据不可恢复。

**请求体** `DestroyStorageRequest`：
```jsonc
{
  "confirm": "app-order-svc"  // 必须精确匹配 app_id（防误操作确认）
}
```

**响应** `HttpResult<String>`：
```jsonc
{ "success": true, "data": "PVC 已销毁，配额已释放" }
```

**错误**：
| HTTP | code | 说明 |
|---|---|---|
| 400 | ERR_VALIDATION | confirm 缺失/不匹配 |
| 409 | ERR_INVALID_STATE | 应用仍存在，需先 delete |
| 500 | ERR_BACKEND_ERROR | PVC 卡 Terminating（需运维介入） |

**curl**：
```bash
curl -X POST $RCODER/api/v1/apps/app-order-svc/storage/destroy \
  -H 'Content-Type: application/json' \
  -d '{"confirm":"app-order-svc"}'
```

## 数据库管理（app-runtime 镜像内置 PG）

> 仅适用于使用 app-runtime 镜像（内置 PostgreSQL 16）的应用。rcoder 通过 exec 容器内 psql 操作。

### POST `/apps/{app_id}/db/reset-password` — 重置应用内 PG 密码

**请求体** `ResetDbPasswordRequest`：
```jsonc
{
  "new_password": "NewSecurePass123"  // 新密码（非空）
}
```

**响应** `HttpResult<String>`：`"密码已重置"`

**错误**：
| HTTP | code | 说明 |
|---|---|---|
| 400 | ERR_VALIDATION | 应用无 PG / 密码为空 |
| 404 | ERR_APP_NOT_FOUND | 应用不存在 |

---

### POST `/apps/{app_id}/db/create-database` — 新建数据库

**请求体** `CreateDatabaseRequest`：
```jsonc
{
  "database": "mydb",        // 新数据库名（PG 标识符规则）
  "owner": "appuser"         // 可选 owner 用户名（默认不指定）
}
```

**响应** `HttpResult<String>`：`"数据库已创建"`

**错误**：
| HTTP | code | 说明 |
|---|---|---|
| 400 | ERR_VALIDATION | 应用无 PG / 数据库名不合法 |
| 404 | ERR_APP_NOT_FOUND | 应用不存在 |
| 409 | ERR_ALREADY_EXISTS | 库已存在 |
